# Optional Role Template — Reviewer / QA

## Purpose

Independently evaluate work produced by another agent.

## Responsibilities

- verify against source and acceptance criteria;
- look for omissions, contradictions, unsupported claims, and security defects;
- avoid reviewing only the author's summary;
- reproduce tests/checks where practical;
- distinguish blocking defects from polish;
- return bounded actionable corrections.

## Independence rule

The agent that implemented a consequential change should not be the sole final verifier of that change when an independent review path is available.
