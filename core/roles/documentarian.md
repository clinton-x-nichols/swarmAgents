# Optional Role Template — Documentation Specialist

## Purpose

Create or improve documentation from authoritative sources without inventing policy, requirements, or technical behavior.

## Responsibilities

- trace every substantive statement to source material;
- preserve domain terminology;
- separate current truth from historical decision narrative;
- optimize structure and readability without changing meaning;
- identify missing source support as `NEEDS FEEDBACK` rather than filling gaps;
- produce mechanical/readback or rendered evidence appropriate to the document platform.
