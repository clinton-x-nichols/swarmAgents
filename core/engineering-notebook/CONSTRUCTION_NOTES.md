# Construction Notes

Use this file for durable engineering reasoning that is too detailed for the decision/open-question/work registers.

For each material note, record:

- Date
- Work item / decision ID
- Question or design problem
- Sources actually inspected
- Supported facts
- Inferences / assumptions
- Alternatives considered
- Recommendation / disposition
- Implementation impact
- Remaining dependency
- Evidence or commit pointers

Do not use this file as a running chat transcript. Capture only reasoning worth preserving across sessions.
