# ChatGPT Orchestrator Bootstrap Prompt — Template

Use the generated version in `generated/chatgpt-bootstrap-prompt.md` after running `scripts/bootstrap_swarm.py`.

The generated prompt instructs the Orchestrator to:

- fresh-read this repository;
- avoid starting project execution before commissioning;
- interview the Owner;
- research current public role/prompt patterns;
- present adopt/adapt/build choices;
- finalize roles and authority;
- populate durable state;
- commission the Worker;
- run QA smoke tests.
