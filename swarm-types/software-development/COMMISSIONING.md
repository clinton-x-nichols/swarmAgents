# Software-development swarm commissioning focus

Establish product goal, architecture and repository boundaries, supported platforms, coding standards, test strategy, CI system, dependency/security policy, environments, deployment authority, rollback expectations, observability, performance constraints, and definition of done.

Role/prompt research should look for current coding-agent, architect, implementer, test-engineer, code-reviewer, security-review, CI-debugging, and release-agent patterns. Do not import prompts that presume broader tool permissions than the Worker actually has.
